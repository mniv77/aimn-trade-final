V13.13 — ALL TRAJECTORY SEQUENCE AUDIT
--------------------------------------
Base research question:
Does the complete chronological trajectory contain information that is lost
when the trajectory is reduced to its final/current state?

23 trajectory cases were examined.

Important methodological correction:
The chronological sequence must preserve state re-entry. Consecutive duplicate
states are compressed, but a state returning later is retained.

Meaningful trajectory states:
- NEUTRAL
- RECOVERING
- DETERIORATING
- PERSISTENT_FAILURE

Examples demonstrated that trajectories can contain repeated deterioration/
recovery cycles and that the final state can hide important prior deterioration.

V13.14 — SEQUENCE INFORMATION-GAIN AUDIT
-----------------------------------------
Question:
Does complete chronological state history contain predictive information that
current/final state alone does not?

At checkpoints +10/+15/+20/+25/+30/+45/+60:
- Current state = latest state at that checkpoint.
- Chronological sequence = all state changes through that checkpoint,
  with only consecutive duplicates compressed.
- Future return is measured from the checkpoint, not from the original
  opposite-transition detection.

The comparison is deliberately within the same current state at the same
checkpoint. This prevents a motif from merely appearing predictive because
it is associated with a different current state.

Only repeated exact sequence groups are considered for information-gain-style
comparison. Unique sequences are not treated as validated patterns.

Research only:
- No AI model trained.
- No production engine changed.
- No order logic changed.

V13.14 confirmed that raw trajectories preserve re-entry patterns such as:
OPPOSITE_DETECTED -> PERSISTENT_FAILURE -> DETERIORATING -> PERSISTENT_FAILURE
and:
OPPOSITE_DETECTED -> DETERIORATING -> RECOVERING -> NEUTRAL -> DETERIORATING
and:
OPPOSITE_DETECTED -> DETERIORATING -> RECOVERING -> DETERIORATING ->
PERSISTENT_FAILURE

These examples reinforce that a trajectory is potentially richer than a
single final-state label.

V13.15 — SEQUENCE MOTIF INFORMATION AUDIT
------------------------------------------
Question:
Does chronological motif history add information beyond CURRENT STATE?

120 motif observations were produced after repairing the future-return
calculation.

Future return was correctly reconstructed from each StatePoint.return_pct:
- LONG: price factor = 1 + return_pct/100
- SHORT: price factor = 1 - return_pct/100

The central comparison remained:
motif observations versus ALL observations having the SAME CURRENT STATE
at the SAME CHECKPOINT, using future return measured from that checkpoint.

Initial motif set accidentally contained duplicate aliases:
- DETERIORATING -> RECOVERING
- RECOVERY AFTER DETERIORATION

and:
- DETERIORATING -> RECOVERING -> DETERIORATING
- RETURN TO DETERIORATION

This was identified as a methodological problem because the same underlying
trajectory could be counted twice under different names.

One illustrative V13.15 result:
At +15m, current state RECOVERING:
- state baseline N=9
- +15m future return AVG = -0.217%
- +30m future return AVG = -0.284%
- +45m future return AVG = -0.236%

Motif DETERIORATING -> RECOVERING:
- N=3
- +15m AVG = -0.666%
- +30m AVG = -1.029%
- +45m AVG = -1.195%

This is interesting research evidence, but N=3 is too small to validate a
general rule. The duplicate alias produced the same underlying observation
and therefore must not be treated as independent evidence.
